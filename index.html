H&E ↔ DAPI Virtual Staining Translator

Bi-directional virtual staining for histopathology — patches and whole-slide images. Product-grade Pix2Pix + CycleGAN, trained on a 3.7GB CPU-only laptop.

GitHub repo Live training log Releases

Training progress — 183 / 200 epochs (91.5%)

G-loss 2.2603 → 1.5302 (−32%), D-loss ~0.75 stable, no divergence. Per-epoch atomic checkpoints, crash-resume safe.

🔬 Two directions

H&E→DAPI (paired Pix2Pix: CNN-ResNet + Swin + FMF fusion + PatchGAN) and DAPI→H&E (CycleGAN) for unaligned sections.

🧩 Streaming WSI

Per-tile whole-slide translation with no full-slide canvas (4.8GB → 512MB budget) and ONNX export.

💻 Built on 3.7GB, no GPU

Streaming-by-default engineering, resource monitors, and 11 low-RAM regression guards mirrored in CI.

🚀 Deployable

FastAPI backend + drag-and-drop UI, Dockerized; staging image on GHCR.

Quick start

# CPU env
uv pip install --python .venv/bin/python torch torchvision --index-url https://download.pytorch.org/whl/cpu

# inference (patch + streaming WSI)
PYTHONPATH=. .venv/bin/python src/models/infer.py --input data/examples/he_example.png --direction he2dapi --out /tmp/synth.png

# train (resumable, safe to kill/rerun)
PYTHONPATH=. .venv/bin/python -m src.models.train_paired --config configs/hemit_dual_branch.yaml --resume auto --optimize-for lowram
